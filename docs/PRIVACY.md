# MONODESK OS 1.0 — Privacy Policy & Zero-Telemetry Commitment

---

### 1. Zero-Telemetry Commitment

MONODESK OS is engineered with a strict **Zero-Telemetry Policy**:
1. **No Data Collection:** The operating system does not collect, log, or transmit any analytics, device metrics, usage statistics, hardware serials, IP addresses, or personal information.
2. **No Tracking Beacons:** The desktop shell, dock, application launcher, widgets, and first-party applications contain zero tracking pixels, telemetry daemons, or background phoning-home routines.
3. **Hardware Redaction:** The native `monodesk-hardware-centre` diagnostic tool automatically masks and redacts all MAC addresses, device serial numbers, and storage UUIDs before displaying or exporting system reports.
4. **No Mandatory Online Accounts:** MONODESK OS does not require user accounts, email registration, cloud logins, or internet connectivity to install or operate.
5. **Private Local AI:** The optional Local AI Assistant operates exclusively on local device hardware (`127.0.0.1:11434`) and never transmits prompts or completions across the network.
